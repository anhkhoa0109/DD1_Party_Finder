# DD1 Party Finder — V1.1

Mobile-first offline/PWA party planner for Darkest Dungeon 1.

## Included
- Individual recruited hero instances.
- READY / NOT READY per individual hero instance.
- Rank-aware matching with duplicate hero support.
- Available Now and One Hero Away.
- Recommended / Situational / Fun categories.
- Rating, Best For, Strengths and Weaknesses.
- Search; dedicated Party Filter intentionally deferred.
- LocalStorage autosave + JSON Export/Import.
- Offline PWA / GitHub Pages friendly.
- Phone-first vertical layout for iPhone XR and similar screens.
- Bundled original vector portrait placeholders for offline use.

## Data note
The practical database is a curated synthesis of recurring community recommendations and composition archetypes. Ratings are editorial/community-consensus estimates, not in-game scores.
Party names are secondary metadata because the game's named-party mechanic is cosmetic.
