DD1 Party Finder V1
====================
Target: iPad mini 5 / Safari
Architecture: static HTML/CSS/JS + localStorage
No server, backend, framework, or account required.

How to test:
1. Open index.html in a browser.
2. Tap a hero to add one ready hero; tap repeatedly for multiple copies.
3. Right-click/secondary click reduces the count.
4. Matching is exact by class AND Rank 4 -> Rank 1 order.
5. Reset clears the roster.

For iPad:
- The simplest deployment is to host this folder as a static site (e.g. GitHub Pages), open it in Safari, then Share -> Add to Home Screen.
- Once installed as a PWA, the static assets can be cached for offline use after the first load.

Data note:
V1 intentionally labels the dataset as a starter/verified dataset rather than claiming all 413 combinations are included. The official wiki currently lists 413 named DD1 combinations.
